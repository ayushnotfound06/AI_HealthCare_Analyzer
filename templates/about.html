About the project

Built for smarter learning.

A 3rd Year Minor Project exploring how machine learning can support structured healthcare-related analysis.

PROJECT OVERVIEW

AI HealthCare Analyzer

This project combines a symptom-based disease classifier with a heart-disease risk screening model in one web interface. The goal is to demonstrate a practical machine-learning workflow from user input to model output.

The application is intended for educational and demonstration purposes. Its predictions should not replace evaluation or advice from a qualified healthcare professional.

PROJECT FLOW
01User input

Symptoms or clinical values are entered through the interface.

02ML inference

The corresponding trained model processes the supplied features.

03Structured output

The application presents the model response in a readable format.
